# Proyecto Parcial I: Predicción del rendimiento académico (Paralelo 4-2, Grupo E)

Mantenga `student-mat.csv` en la misma carpeta que el notebook. En el PC o Codespaces, para usar los archivos de `partes/`, copie allí el CSV. En Colab, selecciónelo cuando se solicite.

- `ProyectoP1_Paralelo4-2_GrupoE.ipynb`: proyecto completo (entregable de la guía).
- `partes/`: Partes 1 a 5 y bono; cada archivo se ejecuta solo.

## Google Colab
1. Archivo > Subir notebook (o abrirlo desde la pestaña GitHub).
2. Entorno de ejecución > Ejecutar todas.
3. Si lo solicita, seleccione `student-mat.csv`.

## En el PC (Python 3.10 o superior)
    pip install -r requirements.txt
    jupyter notebook ProyectoP1_Paralelo4-2_GrupoE.ipynb

## En línea con GitHub
- **Codespaces:** Code > Codespaces > Create codespace. En la terminal: `pip install -r requirements.txt`, abra el notebook, elija el kernel de Python y pulse *Run All* (requiere las extensiones Python y Jupyter).
- **Actions:** la pestaña Actions ejecuta el notebook en cada push y comprueba que no tenga errores.

La vista normal de GitHub muestra el notebook con sus resultados, pero no lo ejecuta.
